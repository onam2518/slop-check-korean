# 한국어 어문 규범 교정

AI 슬롭 제거(`korean.md`)와 별개로, 한국어 글의 **어문 규범 오류**를 잡는 체계. 슬롭은 "AI 티"이고, 이건 사람도 AI도 내는 문법·표기·구성 오류다. 프로젝트가 만들어 내는 한국어 글을 검수할 때 두 가지를 함께 본다.

체계와 우선순위는 국립국어원 2024 「글쓰기 첨삭 지원 지시문 기반 생성 말뭉치」(GWIG2402606300, 1,500건)의 오류 분류와 실제 첨삭 빈도에서 뽑았다. 오류 유형과 어문 규범은 공개 규범이며, 코퍼스 원문·AI 생성 피드백은 옮기지 않았다.

## 네 가지 층위

첨삭은 네 유형으로 나뉜다. 대상 단위가 다르다.

| 유형 | 단위 | 무엇을 본다 |
|------|------|-------------|
| 표기 | 문장 | 맞춤법·표준어, 띄어쓰기, 문장 부호, 외래어 표기 |
| 표현 | 문장 | 높임·조사·호응·피동/사동·어순·연결·시제 등 문장 성립 |
| 내용 | 문단·문서 | 주제 일관성, 근거의 적절성·구체성, 사실성 |
| 조직 | 문단·문서 | 중심-뒷받침 연결, 이탈 문장, 문장 간 연결 |

## 실측 우선순위 (빈도순)

실제 첨삭에서 가장 자주 걸린 순서. 검수 시간이 짧으면 위에서부터 본다.

1. **한글 맞춤법·표준어 규정** (가장 많음) — 소리대로 적되 어법에 맞게. 사이시옷, 두음 법칙, 어미·접미사 표기 등.
2. **띄어쓰기** — 조사는 붙이고, 의존 명사·단위·열거는 띄운다(한글 맞춤법 제41~50항). "수단중" → "수단 중".
3. **호응 및 시제** — 주어-서술어, 목적어-서술어, 부사어-서술어, 수식어-피수식어 호응. 지나치게 긴 수식어, 문장 성분 생략, 대용 표현, 시제 일관.
4. **조사** — 격 조사, 인용격 조사, 접속 조사, 보조사, 조사의 생략·남용.
5. **문장 부호** — 마침표·쉼표·따옴표·쌍점·줄표·줄임표 규정.
6. **높임** — 상대 높임, 주체 높임, 객체 높임. 주어가 높임 대상이 아닌데 '-(으)시-'를 쓰지 않기("국가가 …하시는" → "하는"). '어르신 분'처럼 높임 중복 피하기.
7. **외래어 표기법** — 규정된 표기로("컨텐츠" → "콘텐츠").
8. **피동·사동** — 이중 피동("되어지다", "불려지다") 금지, 부적절한 사동 피하기.
9. **어순** — 부자연스러운 어순 바로잡기.

## 자동 맞춤법 검사

표기(맞춤법·띄어쓰기·문장 부호)는 감으로 단정하지 말고 검사기로 확인한다. `bin/spellcheck.js`가 부산대·나라인포테크 한국어 검사기(jhaemin/speller-api)를 호출해 권위 있는 후보를 준다.

```bash
node <skill-dir>/bin/spellcheck.js "수단중에 하나에요"        # 틀린 부분 → 후보 + 설명
node <skill-dir>/bin/spellcheck.js --file draft.md --json     # 기계 판독용(offset 포함)
echo "문장" | node <skill-dir>/bin/spellcheck.js
```

- 응답은 `{틀린 표기 → 후보, 설명}` 목록이다. **후보이지 자동 치환이 아니다.** 문맥·고유명사·전문어·의도된 표기는 사람이 판단한다. 검사기가 못 잡는 것(호응·논리·문체)은 이 문서의 나머지 항목과 사람 판단으로 본다.
- **프라이버시**: 검사할 텍스트가 외부 서비스(`speller.town` → 부산대 검사기)로 전송된다. 비밀·개인정보는 검사하지 않는다. 사내 처리가 필요하면 jhaemin/speller-api를 자체 호스팅하고 `KO_SPELLER_ENDPOINT`를 지정한다. 공개 업스트림은 Cloudflare 봇 차단이 있어, 막히면 자체 호스팅을 권한다.
- 검사기가 없거나(엔드포인트 불통) 텍스트가 민감하면 이 단계를 건너뛰고, 규범이 애매한 표기는 단정하지 말고 국립국어원 맞춤법 검사기·표준국어대사전 확인을 안내한다.

## 표현 오류 유형 (문장, 25종)

문장 층위에서 점검하는 전체 목록:

- 부적절한 높임법 사용 (상대/주체/객체 높임)
- 부적절한 조사 사용
- 부적절한 피동 표현 / 부적절한 사동 표현
- 주어와 서술어 / 목적어와 서술어 / 부사어와 서술어 / 수식어와 피수식어의 부적절한 호응
- 지나치게 긴 수식어 사용
- 필요한 문장 성분 생략
- 부적절한 연결(대등·종속 접속) / 부적절한 접속어 / 부적절한 연결어미 / 부적절한 종결어미 사용
- 부적절한 대용 표현 사용
- 부적절한 시제 사용
- 어순의 부자연스러움
- 한글 맞춤법과 표준어 규정 위반 / 띄어쓰기 규정 위반
- 문장 부호 생략 및 부적절한 사용
- 외래어 표기법 위반 / 외국어와 외래어 오남용
- 문법상 잘못된 표현 / 어휘상 잘못된 표현 사용
- 로마자 표기법 규정 위반

## 내용 점검 질문 (문단·문서)

- 중심 문장과 뒷받침 문장은 무엇인가?
- 주제가 무엇이며, 그 주제를 잘 드러내는가?
- 처음부터 끝까지 같은 주제로 쓰는가? (일관성)
- 뒷받침 내용이 적절하고 구체적인가?
- 사실이 아니거나 비윤리적인 내용은 없는가?

## 조직 점검 질문 (문단·문서)

- 중심 문장과 뒷받침 문장이 자연스럽게 연결되는가?
- 필요 없거나 흐름에서 벗어난 문장은 없는가? (있으면 지목)
- 문장을 긴밀하게 잇는 연결 표현을 적절히 썼는가?

## 교정 출력 형식

첨삭 결과는 근거를 붙여 제시한다(코퍼스의 첨삭 형식):

> 제시 문장에 **<오류 유형>**이 관찰됩니다. <어문 규범 조항/근거>에 따르면 <왜 어긋나는지>. 그러므로 **<수정문>**으로 바꾸어 보시길 제안합니다.

`audit` 모드에서는 오류 유형·근거·수정안을 제시하고 다시 쓰지는 않는다. `edit` 모드에서는 수정 후 무엇을 왜 바꿨는지 함께 준다.

## 가드레일

- **과잉 교정 금지.** 글쓴이가 의도한 문체·구어체·방언·강조는 오류가 아니다. 슬롭 규칙과 같은 보존 원칙을 따른다(`preservation.md`).
- **사실 보존.** 숫자·이름·인용은 그대로. 없는 내용을 채우지 않는다.
- **맞춤법·띄어쓰기는 후보로 다룬다.** 위 「자동 맞춤법 검사」로 확인하되, 검사기 결과도 확정이 아니라 제안이다. 고유명사·전문어·의도된 표기는 사람이 판단하고, 규정이 애매하면 표준국어대사전으로 확인한다. 표준 용어는 `korean-terminology.md`의 API로 조회한다.
- **규범 위반이 아니면 취향으로 강요하지 않는다.** 규정에 어긋난 것만 "오류"로, 나머지는 제안으로 구분한다.

국립국어원 2024 글쓰기 첨삭 지원 지시문 기반 생성 말뭉치(GWIG2402606300). 코퍼스 출력은 gpt-4o 생성 + 전문가 검토물이라, 이 문서는 그중 국립국어원 어문 규범에 근거한 **오류 분류 체계와 빈도**만 반영했다. 규범 원문은 국립국어원 「한글 맞춤법」·「표준어 규정」·「외래어 표기법」·「국어의 로마자 표기법」을 따른다.
