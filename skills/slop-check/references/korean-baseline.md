# 한국어 실증 기준선

한국어 검수 규칙을 실제 사람이 쓴 문장에 맞춰 보정한 근거. 감이 아니라 측정값으로 임계를 정한다.

## 코퍼스

국립국어원 2025 「문장 간 논리 관계 판별」 말뭉치(NIKLUGE-2025). 문장쌍(`front`/`back`)에 논리 관계 라벨(순접/역접/양립)이 붙은 데이터. 우리는 라벨이 아니라 **사람이 쓴 문장 자체를 자연스러운 한국어 기준선**으로 썼다.

- train 1,347쌍 · dev 269쌍 · test 1,077쌍
- 추출한 사람 문장: 5,386개(중복 포함), 대체로 설명·서술문

라이선스: NIKL 배포 자료. 코퍼스 원본은 저장소에 넣지 않았다. 회귀 테스트용으로 30문장만 `tests/fixtures/human-ko.txt`에 발췌했다.

## 측정값 (2026-08-25)

| 지표 | 값 |
|------|-----|
| 문장당 어절 수 | 평균 15.4, 중앙값 15, p90 24, 최대 50 |
| 12어절 초과 문장 | **64%** |
| 문장당 글자 수 | 평균 65, 중앙값 61 |
| burstiness(어절 길이 CoV, 코퍼스 전체) | 0.41 |

## 이 값으로 내린 결정

1. **문장 길이는 한국어 슬롭 신호가 아니다.** 사람 문장의 64%가 12어절을 넘는다. naradesign의 "12어절"은 다듬기 지향점이지 오탐 기준이 아니다. 린터는 절대 길이로 문장을 감점하지 않는다. → `korean.md` 「글쓰기 기본 원칙」에 반영.
2. **한국어의 신호는 길이의 균일함이다.** 사람 글은 짧고 긴 문장이 섞인다. 린터는 영어용 통계(TTR·트라이그램)를 한국어에서 끄고 uniformity 가중치를 0.1로 낮춘다. burstiness는 어절 기준으로 계산해 참고값으로만 쓴다.
3. **한국어 규칙의 오탐률이 낮음을 확인.** 사람 문장 400개에 린터를 돌리니 16/100(clean), 마커 히트 3개(매우 중요한·중요한 것은·강력한). 자연스러운 사람 글을 슬롭으로 오인하지 않는다. → 규칙 가중치를 바꿀 이유 없음.

## register 실측: 표준 문어 (신문 기준)

표준 문체 페르소나(`persona.md`)의 기본값은 감이 아니라 신문 말뭉치 실측에서 나왔다. 신문체가 문어 문체 생성의 표준 register다. NIKL 신문 말뭉치 2025에서 86만 문단(93MB, 9파일 표본)을 측정.

| 항목 | 값 |
|------|-----|
| 목적 연결어미 (기 위해·위하여·고자 : 려고·려는) | 58,725 : 5,046 = **11.6 : 1** |
| 종결 | `~다.` 988,811 · `~습니다.` 3,112 · `~요.` 2,213 |
| 문장 길이(어절) | mean **17.3**, median **16**, p10 7, p90 30 |
| em dash(—) | 3 (≈0) · 이모지 0 |
| 따옴표 | 굽은따옴표 675,988 · 곧은따옴표 0 |
| 그 외 표기 | 가운뎃점(·) 207,723 · 물결표(~) 24,675 |

확정된 표준 문어 기준선:

1. **목적은 `~기 위해`류.** 격식:구어 11.6:1. (논술문 코퍼스도 7.2:1로 같은 방향.)
2. **종결은 `~다`.** 신문은 문어 평서체가 사실상 전부다. `~습니다`(합쇼체)·`~요`(해요체)는 공지·안내·대화 등 다른 register의 것. register는 이분법이 아니다.
3. **문장 길이 밴드 = 대략 7~30어절, 중앙값 16.** 12어절은 상한이 아니라 지향점이다. 다만 균일한 중간 길이 나열은 피하고 짧은 문장과 섞는다(p10 7 ~ p90 30의 폭).
4. **em dash·이모지 없음이 표준.** 신문 93MB에 em dash 3개, 이모지 0. "em dash 금지"가 실측으로 확증됐다.
5. **한국어 따옴표는 굽은따옴표(“ ”, ‘ ’)가 표준.** 신문 곧은따옴표 0. 영어/코드용 "곧은 따옴표" 규칙을 한국어 산문에 적용하지 말 것 — 한국어에서 굽은따옴표는 슬롭이 아니다. 가운뎃점(·)·물결표(수치 범위 3~4)도 정상 표기.

측정: `scratchpad/register_measure.py` 계열 스크립트. 재현하려면 신문 JSON(`document[].paragraph[].form`)에서 위 빈도를 카운트한다. 큰 파일(최대 1GB)은 표본으로 처리한다.

## 크래프트 지표 (잘 쓴 글의 실측 목표)

표준을 "규범만 맞는 글"이 아니라 "잘 쓴 글"로 끌어올리기 위해, 두 종류의 잘 쓴 한국어에서 크래프트 신호를 측정했다. **신문**(전문 기자, 6,000편/88k문장)과 **문어 책-정보**(저작권 해결 비문학 도서 — 사회과학·철학·역사·기술과학 등, 600권/180k문장; 문학은 제외). 두 코퍼스를 비교하니 어떤 신호가 보편이고 어떤 게 장르 특유인지 갈렸다.

| 지표 | 신문 | 문어 비문학 | 해석 |
|------|------|------------|------|
| 어휘 다양성 (TTR 200토큰) | 0.82 | **0.86** | **보편**. 잘 쓴 글일수록 높다. AI 슬롭은 낮음(단어·상투어 반복) |
| 문장 리듬 (burstiness, 글 안 길이 변동) | 0.45 | **0.49** | **보편**. 짧고 긴 문장을 섞는다 |
| 구체성 (숫자 포함 문장 비율) | 0.57 | **0.10** | **장르 특유**. 저널리즘은 수치 밀집, 개념적 비문학은 아님 |
| 문장 길이(어절) | 중앙값 15 | 중앙값 10 | **장르 의존**. 고정 목표 아님 |

표준이 지향할 것 (→ `writing-system.md`):

1. **어휘를 돌려막지 않는다 (보편, 가장 견고).** 잘 쓴 글의 TTR는 0.82~0.86. 같은 단어·동의어 순환·상투어 반복이 다양성을 떨어뜨린다. 명확한 단어는 반복하되, 뭉뚱그린 상투어로 채우지 않는다. AI 슬롭이 가장 확실히 지는 지점.
2. **글 안에서 길이를 섞는다 (보편).** burstiness 0.45~0.5가 사람 기준. 짧은 문장과 긴 문장을 섞어 균일한 리듬을 깬다. (린터 stats의 burstiness 임계 0.45가 실측 검증됨.)
3. **뭉뚱그리지 말고 구체적으로 (구체 형태는 register에 맞게).** "생산성을 높였다"가 아니라 구체적으로. 단, **구체성이 곧 숫자는 아니다** — 저널리즘은 문장 절반이 숫자지만(0.57), 개념적 비문학은 숫자가 드물다(0.10). 사실·수치 밀집 글에서는 수치를, 개념·논설 글에서는 이름 붙은 개념·사례·메커니즘을 싣는다. 없는 수치는 지어내지 않는다.
4. **문장 길이는 목표가 아니다.** 신문 15어절, 개념적 도서 10어절로 장르마다 다르다. 절대 길이로 재지 말고 균일함만 경계한다.

한계: 문어 표본은 번역서가 섞여 있을 수 있어(번역투 위험), 연결어미·종결의 register 표준은 여전히 신문(네이티브 기자)을 기준으로 둔다. 문어는 어휘·리듬 같은 **크래프트 층**을 강화하는 용도다. 문학(책-상상)은 대화체·비유가 많아 중립 표준에서 제외했다.

## 회귀 테스트

`tests/fixtures/human-ko.txt`(사람 문장 30개, 평균 15어절, burstiness 0.48)는 **낮게(< 30) 나와야 한다**. `tests/smoke.sh`가 이를 검사한다. 한국어 규칙을 강화하다가 자연스러운 사람 글을 잡기 시작하면 이 테스트가 실패한다.

전체 코퍼스로 다시 측정하려면(있을 때):

```bash
# 사람 문장을 뽑아 점수 확인
python3 - <<'PY'
import json,glob
sents=[]
for f in glob.glob('/path/to/말뭉치_*/*.json'):
    for x in json.load(open(f)):
        i=x.get('input',{})
        sents+=[i[k] for k in ('front','back') if i.get(k)]
open('/tmp/human_ko.txt','w').write('\n\n'.join(sents[:400]))
PY
node skills/slop-check/bin/sloplint.js score /tmp/human_ko.txt   # < 25 기대
```

숫자가 크게 달라지면(예: 사람 문장이 40점 이상) 규칙이 과하게 잡는 것이니 완화한다.
